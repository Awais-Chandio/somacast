# Brand fonts

Fira Sans, Overpass and Fira Code, all under the SIL Open Font License 1.1.
The licence texts are in `OFL-FiraSans.txt`, `OFL-Overpass.txt` and `OFL-FiraCode.txt`.

Copied from the npm packages `@expo-google-fonts/fira-sans` (0.4.1), `@expo-google-fonts/overpass` (0.4.2) and `@expo-google-fonts/fira-code` (0.4.1), then renamed.
The file names match the `font` tokens in `packages/core/src/tokens.ts`.

| File | Source file |
|---|---|
| FiraSans-Black.ttf | FiraSans_900Black.ttf |
| FiraSans-Bold.ttf | FiraSans_700Bold.ttf |
| Overpass-Regular.ttf | Overpass_400Regular.ttf |
| Overpass-SemiBold.ttf | Overpass_600SemiBold.ttf |
| Overpass-Bold.ttf | Overpass_700Bold.ttf |
| Overpass-Italic.ttf | Overpass_400Regular_Italic.ttf |
| FiraCode-Regular.ttf | FiraCode_400Regular.ttf |
| FiraCode-Bold.ttf | FiraCode_700Bold.ttf |

Not yet linked into the React Native app.
